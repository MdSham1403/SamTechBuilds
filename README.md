## 🚀 Deployment

The website is hosted using Netlify.

To deploy updates:

1. Push your latest changes to the connected GitHub repository.
2. Netlify will automatically build and deploy the updated website if continuous deployment is configured.
3. Verify the live website after deployment.

## 🔐 Configuration

Some website functionality requires configuration.

For the contact and notification integration, configure the required environment variables in Netlify:

```env
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

**Security:** Never commit bot tokens, API keys, passwords, or other secrets to GitHub. Store them securely in Netlify environment variables.

Update project URLs, contact details, and other website settings in the appropriate configuration file before deployment.
